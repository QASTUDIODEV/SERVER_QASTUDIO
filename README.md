# 🛠 QAStudio란?

**QAStudio**는 AI를 이용한 웹 서비스의 QA을 위한 자동화 테스트 생성 및 스크립트 관리와 실행을 지원하는 플랫폼 입니다.  
테스터는 AI를 통해 자동으로 스크립트를 생성할 수도 있고 직접 테스트 케이스를 작성하고, 실행하며, 결과를 저장 및 모니터링할 수 있습니다.

> "QA를 보다 쉽게!"

### ✅ 주요 기능
- 📝 **AI 프로젝트 구조 생성**
- ⚙️ **QA 스크립트 생성 및 수정**
- 🚀 **AI 자동 QA 스크립트 생성**
- 📈 **테스트 성공 에러 결과 기록**
- 👥 **테스트 에러 시 스크린샷 제공**

### 📋 Commit Message Convention
| Tag | Description |
| :---: | --- |
| ✨ `Feature` | 새로운 기능 추가 |
| 🐞 `Fix` | 버그 수정 |
| 📃 `Docs` | 문서 추가, 수정, 삭제 |
| ✅ `Test` | 테스트 코드 추가, 수정, 삭제 |
| 🎨 `Style` | 마크업 및 스타일 변경 |
| 🔨 `Refactor` | 코드 리팩토링 |
| ⚙️ `Setting` | 개발 환경 설정 관련 변경 |
| 🚀 `Deploy` | 배포 관련 변경사항 |
| 💻 `CrossBrowsing` | 브라우저 호환성 관련 변경 |
